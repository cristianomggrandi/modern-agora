# Modern Agora

A Modern Agora é uma aplicação de um mercado descentralizado que utiliza o protocolo [Nostr](https://nostr.com/), que conecta todo o mundo e permite negociações sem intermediário.

Disponível em: https://modern-agora.vercel.app/

## Tecnologias

Utiliza Next.js, Typescript, Tailwind CSS, Nostr Development Kit e WebSockets.

## Execução

```bash
npm run dev
```
